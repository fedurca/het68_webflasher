Firmware a hardware het68

Open-source projekt github.com/fedurca/het68 — 6kanálová I2S USB zvuková karta a platforma prostorové akustiky.

Co firmware dělá

Zařízení het68 se chová jako 6kanálové USB mikrofonní zařízení (UAC2). Zachytává šest nezávislých I2S linek z MEMS mikrofonů ICS-43434, data přesouvá DMA a streamuje je do hostitele přes TinyUSB.

  • USB Audio Class 2.0 · isochronní IN
  • 6 kanálů · 48 kHz · 24-bit packed (S24_3LE)
  • PIO + DMA capture, produktový řetězec pro DOA / detekci
  • Podepsané firmware image · nasazení přes web flasher
