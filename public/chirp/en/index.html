        HET68 chirp link (spec 1.4.0, version 2): BPSK preamble + 2‑FSK frequency-hopping data,
        CDMA m‑sequence (8 nodes), 31‑byte frame (version, node, type, seq, flags, key/nonce,
        0–16 B payload), CRC32 only (no FEC). RX and TX run locally in the browser.
        
Note: the spec targets a resonant 4 kHz piezo; phone speakers roll off
        above ~3 kHz, so the browser profile moves the link to the
        1.4–2.8 kHz band (2 kHz preamble) and lengthens chips (~1 s
        frame). Not wire-compatible with 4 kHz hardware. 48 kHz and adequate volume/proximity work best.
