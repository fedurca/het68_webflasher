Overview

HET68 is a 6-channel edge spatial-acoustics platform on RP2350. The device appears as a UAC2 USB sound card while computing DOA / detections locally.

Architecture

  • 6× MEMS ICS-43434 → PIO / DMA → USB Audio Class 2.0
  • Edge inference on-device (cloud not required for basic detection)
  • Optional companion HW behind the sound card for long-term recording and audio pull via API
  • Cloud / on-prem gateway for site management and track fusion

Audio path

48 kHz / 24-bit, 6 synchronous channels. Beamforming and classification run at the edge.

Audio pipeline diagram — soon

Mesh & synchronization

Nodes can synchronize via acoustic ALINK chirp or network time. Multiple points enable 3D triangulation of trajectories.

Security

The design anticipates upcoming ISO/IEC 27001 (ISO 27k) certification and secure by design: least-privilege API keys, TLS, audit log, minimal raw-audio retention.
