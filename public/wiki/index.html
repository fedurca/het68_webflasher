Přehled

HET68 je 6kanálová edge platforma prostorové akustiky na RP2350. Zařízení vystupuje jako UAC2 USB zvukovka a zároveň počítá DOA / detekce lokálně.

Architektura

  • 6× MEMS ICS-43434 → PIO / DMA → USB Audio Class 2.0
  • Edge inference na zařízení (bez nutnosti cloudu pro základní detekci)
  • Volitelný companion HW za zvukovkou pro dlouhodobý záznam a audio pull přes API
  • Cloud / on-prem gateway pro správu lokalit a fúzi tracků

Audio cesta

48 kHz / 24-bit, 6 synchronních kanálů. Beamforming a klasifikace běží na hraně.

Schema audio pipeline — brzy

Mesh & synchronizace

Uzly se mohou synchronizovat akustickým ALINK chirpem nebo síťovým časem. Více bodů umožňuje 3D triangulaci trajektorií.

Bezpečnost

Návrh počítá s připravovanou certifikací ISO/IEC 27001 (ISO 27k) a principem secure by design: least privilege API klíče, TLS, audit log, minimální retenze surového audia.
