HET68 API

REST rozhraní pro kalibraci, synchronizaci, nastavení a detekce. Pokud je za USB zvukovkou další hardware (recorder / companion MCU), API umí i stahovat zvuk.

openapi.yaml Technická wiki ISO 27k & security

Struktura (návrh)

  • Health / capabilities — co uzel umí (včetně audioPull)
  • Calibration — self-noise, tone sweep, mesh geometrie
  • Sync — chirp / NTP / PTP, role master–follower
  • Settings — detekční prahy, ALINK profil, privacy retenze
  • Detections — query + SSE stream, site-wide fúze
  • Audio — seznam klipů a download WAV/FLAC (jen s companion HW)
  • Audit — podpora kontrol ISO/IEC 27001
